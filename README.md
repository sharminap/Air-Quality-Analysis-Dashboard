 Air Quality Insights Dashboard (Excel-Based)
 
This project presents an interactive dashboard built using Microsoft Excel to visualize and analyze real-time air quality data across Indian states and cities. The dataset was sourced from the official Government of India open data platform, data.gov.in.

📌 Key Features

Dynamic slicers and dropdowns to filter by state and city
Visualization of most polluted cities and dominant pollutant types
Comparison of average, minimum, and maximum pollutant levels
Charts include bar, pie, donut, and line charts for effective storytelling
Clean and intuitive dashboard layout for user-friendly interaction

📁 Dataset

Source: data.gov.in
Format: CSV (imported and cleaned in Excel)
Fields: State, City, Station, Pollutant Type, Pollutant Min/Max/Avg, Coordinates, Last Updated

🛠 Tools Used

Microsoft Excel
Pivot Tables
Pivot Charts
Slicers & Data Validation
Conditional Formatting

🎯 Project Objectives

Identify the most polluted states and cities in India
Analyze pollutant severity using average, min, and max values
Compare the distribution of various pollutant types
Build a responsive and visually engaging dashboard
